Online Tutor – AI-Powered Learning Platform

Overview:
Online Tutor is an AI-powered educational platform designed for South African students, fully aligned with the CAPS curriculum. It provides personalized learning resources across all grades, from primary school to Grade 12.

Key Features:

Generates study guides, lesson plans, summaries, and quizzes instantly
Personalized content tailored to each learner
Covers all subjects in the CAPS curriculum
Accessible anytime, anywhere for self-paced learning
Helps learners prepare effectively for assessments

Goal:
To make high-quality, CAPS-aligned learning accessible to every student, supporting understanding, revision, and exam readiness through AI-driven educational content.
